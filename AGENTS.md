# Agent instructions

- Partner workflows, demos, SDK integration examples and anonymized pilot results belong here. Core contract or schema changes go to `specifications`; market research goes to `research`.
- Pin protocol commit, ABI, SDK version, chain ID, registry and satellite addresses. Reject unknown or mismatched environments. Never accept experimental passports in production as official.
- Start with synthetic data and a wallet-free demo. Use Localnet and Amoy for engineering tests. Mainnet requires a separate approved pilot, explicit budget, reviewed artifacts and dedicated test wallets.
- No actual deployments, transactions, real partner data, keys, secrets or publication without specific authorization. Do not imply authenticity, ownership, accreditation or regulatory compliance from a passport alone.
- Both this repository and Mainnet/Amoy records are public. Partner findings must be anonymized and cleared for publication before committing.
