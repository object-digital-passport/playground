# ODP Playground

A partner-facing sandbox for exploring how Object Digital Passport can fit real-world workflows: brands, universities, repair services, artists, museums and other organizations.

This is a public repository. Partner data and credentials must never be committed. This starter is documentation, synthetic fixtures and pilot templates, not a deployed service. There are no live contracts, partner accounts or automatic Mainnet transactions.

Core protocol development belongs in [Specifications](https://github.com/object-digital-passport/specifications). Market and technology research belongs in [Research](https://github.com/object-digital-passport/research). This repository consumes explicitly pinned experimental versions; it does not fork the protocol.

The intended experience is a guided demo without a wallet, then a technical sandbox (Localnet/Amoy), then an approved Mainnet pilot with actual fees and optional sponsorship. The demo must never imply a simulated result was registered on-chain.
