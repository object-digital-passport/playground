# Art

Status: proposed; no live integration yet.

Participants: Artists and galleries. Goal: Creator declarations, documentation, independent assessment.

## Walkthrough

Register a synthetic artwork; export and verify a passport; attach an independent mock assessment; test a changed document.

Start in demo mode, repeat with a pinned compatible test deployment, then evaluate whether an approved Mainnet pilot adds useful evidence. Unsupported operations are recorded as protocol gaps, not faked as on-chain successes.

## Acceptance and limitations

Record successful/failed steps, document integrity, correct environment identification, onboarding time and observed cost where applicable. Passport plus separate statements; physical binding is not proof of authenticity.
