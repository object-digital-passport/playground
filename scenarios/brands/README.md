Status: proposed; no live integration yet.

Participants: Independent brands. Goal: Edition issuance and individual unit identification.

## Walkthrough

Create a synthetic collection; issue an edition; print test QR labels; verify an instance and test duplicate/invalid keys.

Start in demo mode, repeat with a pinned compatible test deployment, then evaluate whether an approved Mainnet pilot adds useful evidence. Unsupported operations are recorded as protocol gaps, not faked as on-chain successes.

## Acceptance and limitations

Record successful/failed steps, document integrity, correct environment identification, onboarding time and observed cost where applicable. Edition activation is not ownership; test clone and transfer threats.
