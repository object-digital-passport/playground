# Digital objects

Status: proposed; no live integration yet.

Participants: Digital artists and designers. Goal: File integrity and creator declarations.

## Walkthrough

Register a synthetic file; export and verify it; change a byte and verify mismatch; add a creator declaration.

Start in demo mode, repeat with a pinned compatible test deployment, then evaluate whether an approved Mainnet pilot adds useful evidence. Unsupported operations are recorded as protocol gaps, not faked as on-chain successes.

## Acceptance and limitations

Record successful/failed steps, document integrity, correct environment identification, onboarding time and observed cost where applicable. Hash is not proof of copyright ownership.
